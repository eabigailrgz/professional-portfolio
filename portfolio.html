How to Customize & Host on GitHub Pages

Zero Build Tools Required

  1. Create a GitHub Repository: Create a new public repo on GitHub named yourusername.github.io.
  2. Upload Your Files: Add this index.html file, your headshot (e.g., headshot.jpg), and your resume.pdf to the root folder.
  3. Enable GitHub Pages: Go to your repo’s Settings → Pages, set Source to Deploy from a branch (main / /root), and click Save. Your site will be live in ~60 seconds!
  4. Optional Cleanup: Once you’re done editing, you can delete the Template Utility Button and #guide-modal blocks from your HTML.
